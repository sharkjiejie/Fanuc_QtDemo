# Fanuc Oi-TF 界面 Demo

这是一个照着发那科 Oi-TF 主画面实现的 Qt 工程，用来给数控应用工程师岗位做展示和二次修改。当前版本包含 LCD 主屏幕、右侧 MDI 键盘、下方机床按键、12 工位刀塔、程序目录和 SQLite 数据存储。

## 运行方式

需要 Qt 5.15 或 Qt 6。

- 用 Qt Creator 打开 `CMakeLists.txt`，配置后直接运行。
- 也可以直接打开 `fanuc_oitf_demo.pro`。

## 工程结构

```text
src/
  main.cpp                 程序入口
  app/MainWindow.*         主窗口和模块组装
  core/MachineController.* 坐标、刀具、程序、命令和运行控制
  core/CoordinateTransform.* Qt QMatrix4x4 齐次坐标变换
  core/GCodeParser.*       G/M 代码程序块解析
  core/GCodeModalEngine.*  G/M/F/S/T 模态状态
  core/MotionPlanner.*     G00/G01/G02/G03 轨迹规划
  core/PlcSimulator.*      M 代码请求/STROBE/FIN 握手仿真
  core/MacroEngine.*       宏程序变量、表达式和控制流
  model/WorkOffset.h       G54-G59 工件坐标和相对坐标状态
  data/AppDatabase.*       SQLite 数据访问
  data/SamplePrograms.*    内置程序目录和完整加工案例
  model/                   刀具和程序数据结构
  ui/CncScreen.*           LCD 屏幕绘制和软键交互
  ui/MdiPanel.*            MDI 键盘
  ui/MachinePanel.*        模式、运行、主轴和点动按键
  ui/PanelStyle.h          共用按钮样式
```

## 想换成本机的画面

修改 `src/core/MachineController.cpp`：

- `kDefaultTools`：12 把刀的默认参数。
- `machineX_` / `machineZ_`：默认机械坐标。

`src/data/SamplePrograms.cpp` 保存离线示例程序；启动时只补充数据库中不存在的程序号，不会覆盖已经编辑过的程序。

`src/ui/MachinePanel.cpp` 里可以继续加按键布局。下方按键合并为三个逻辑区：

- 操作：三列均匀布局，依次显示编辑/自动/MDI、连续运转/切削油/程序确认、单程序块/试运行/选择停止；“单块跳转”为单独文字行，下一行为 /1 /2 /3，最后自动启动/暂停各占一半
- 刀塔/轴向选择：HD1/HD2/HD3、刀塔、X/Z/Y/B/C/ZS、辅助装置
- 手动/主轴：左侧手动/手轮/原点复位、方向键、快速/移动/返回；中间竖线分隔；右侧最上方居中显示“主轴”，下一行 SP1/SP2 均匀分布，下面是动力头/启动/停止/寸动/反转
- 手轮/倍率：x1/x10/x100，上方黑色可旋转手轮，下方独立进给旋钮；不显示百分比数字

`src/ui/CncScreen.cpp` 负责 `OFFSET` 页面按 12 工位刀塔显示 `T01` 到 `T12`。底部“刀偏 / 磨损”软键可切换显示对刀参数和磨耗参数。

程序目录不再是主功能键，而是 `PROG` 页面下的副菜单。进入 `PROG` 后，底部显示“程序 / 目录 / 下一步 / 程序检查 / 操作”，点击“目录”进入程序目录页。

MDI 主键盘支持双符号输入：按键上的主符号直接输入，按一次 `SHIFT` 后输入副符号。其中 `4` 的副符号是 `[`，`5` 的副符号是 `]`。

程序载入后会自动执行语法检查。也可以输入：

```text
CHECK
```

语法错误会显示在 `MESSAGE` 页面，并在 `PROG` 页面用红色标出错误行。

模态引擎会持续维护当前 `G00/G01/G02/G03`、`G20/G21`、`G90/G91`、`G94/G95`、`G96/G97` 以及 `T/F/S/M` 状态，并显示在屏幕右侧。

运动规划器会展开常见车削循环：

- `G71` 外圆粗车
- `G70` 轮廓精车
- `G74` 轴向啄钻
- `G76` 简化六刀螺纹循环

`G71` 第一行的参数按车床半径意义处理：

- `U` 是每刀半径吃刀量，X 为直径显示，所以每刀 X 坐标变化为 `2U`
- `R` 是半径退刀量，退刀时 X 坐标变化为 `2R`
- 每一刀顺序为：X 快速接近、Z 工进切削、先退 Z 到循环起点、再退 X 到安全位置
- 单程序块对所有程序段生效；普通 G/M/T/S 或运动程序段执行完当前段后暂停
- `G71` 内部按一刀作为一个执行单元；切削结束后先停在切削终点，不自动退刀
- 切削终点暂停后，再次启动才执行退刀，先退 Z 再退 X，并在安全位置再次暂停
- 安全位置暂停后再启动进入下一刀，不重新载入程序

宏程序支持：

- 局部变量和公共变量
- 算术、三角函数和取整函数
- `IF/GOTO`
- `WHILE/END`
- G 代码变量替换
- 死循环和展开数量保护

工件坐标和相对坐标：

```text
G54
G55
...
G59
WORK X10 Z20
REL 0 X
REL 0 Z
REL 0 ALL
```

程序查找和替换：

```text
1. 在 MDI 输入框输入 G71
2. 按 ↑ 从当前位置向上查找
3. 按 ↓ 从当前位置向下查找
4. 修改 MDI 输入框内容
5. 按 ALTER 替换当前选中的字符
```

编辑模式下字符操作：

- `← / →`：移动字符光标
- `↑ / ↓`：MDI 输入框为空时移动程序行；有内容时执行向上/向下查找
- `ALTER`：用 MDI 输入内容替换选中字符或光标处字符
- `INSERT`：在光标位置插入 MDI 输入内容
- `DELETE`：删除选中字符或光标处字符

程序行和字符只有切换到编辑模式后才能选中和修改，自动模式下会被拒绝。

复位行为：

- 自动模式按 `RESET`：立即停止程序运行、主轴、冷却、高压油和等待中的 PLC 动作，但不把程序跳到开头
- 编辑模式按 `RESET`：停止动作，并把当前行、选中行和字符光标全部归零到程序开头

M 代码动作：

- `M00` 程序暂停
- `M01` 已选择时，当前程序段结束后暂停
- `M03/M04/M05` 主轴正转/反转/停止
- `M08/M09` 冷却开/关
- `M28` 高压泵油开启；仅当前程序段有效，下一段没有 M28 时自动关闭
- `M93` 主轴正转并打开冷却
- `M30` 程序结束并回到开头

## 测试

CMake 工程包含以下测试：

- `GCodeParserTest`
- `GCodeModalTest`
- `MotionPlannerTest`
- `CoordinateTransformTest`
- `PlcSimulatorTest`
- `MacroEngineTest`
- `SampleProgramsTest`

构建后可以运行：

```text
ctest --test-dir <构建目录> --output-on-failure
```

MDI 输入框支持常用命令，例如 `G00 X50 Z2`、`G01 X32 Z-2 F0.15`、`S500 M03`、`M05`、`T0303`。按 `INPUT` 或回车执行，命令记录会显示在 `MESSAGE` 页面。

坐标和 12 把刀具参数保存在 SQLite 数据库中。每把刀独立保存：

- 对刀时的机械坐标
- 对刀点对应的绝对坐标基准
- X/Z 磨耗、刀尖半径和刀尖方位

绝对坐标计算关系：

```text
ABS = 基准绝对坐标 + (当前机械坐标 - 对刀机械坐标) + 磨耗
```

坐标换算统一通过 `CoordinateTransform` 完成，内部使用 Qt `QMatrix4x4` 仿射变换和逆矩阵，不再在多个模块里重复计算公式。

常用输入：

- `MACHINE X121.822 Z-63.255`：直接设置机械坐标
- `X49.500 Z24.500`：设置当前刀具下的绝对坐标，并反算机械坐标
- `T03 GEO X98.740 Z-65.200`：设置 T03 对刀时的机械坐标
- `T03 REF X50.000 Z0.000`：设置 T03 在对刀点对应的绝对坐标基准
- `T03 WEAR X0.005 Z-0.004`：设置 T03 的磨耗刀补
- `MEASURE X49.5`：保持当前 X 机械位置，把实际测量直径 49.5 保存到当前刀的形状数据
- `MEASURE Z0`：保持当前 Z 机械位置，把当前位置对应的 Z 距离保存到当前刀的形状数据

程序目录也保存在 SQLite 的 `programs` 表中，程序文件目录保存在 `settings` 表中。相关输入：

- `DIR`：打开程序目录页
- `SAVE O1003 NEW_PART`：把当前程序保存为 O1003
- `LOAD O1001`：载入 O1001
- `DEL O1001`：删除 O1001 数据库记录
- `PATH D:/CNC/PROGRAMS`：设置程序文件保存目录

内置完整示例：

- `O1000`：基础阶梯轴粗车和精车
- `O1001`：法兰端面示例
- `O1002`：衬套外圆示例
- `O1003`：完整阶梯轴，包含 `G71/G70`
- `O1004`：带 `G02/G03` 的圆弧轮廓
- `O1005`：深孔啄钻和镗孔
- `O1006`：`M20x1.5` 公制螺纹
- `O1007`：宏变量和 `WHILE/END` 循环
- `O1008`：多刀具、粗车、螺纹和钻孔组合示例
