# 宏程序引擎

## 变量

- 局部变量：`#1` 到 `#33`
- 公共变量：`#100` 到 `#199`、`#500` 到 `#999`

程序展开前会清空局部变量，公共变量在同一个 `MacroEngine` 生命周期内保留。

## 表达式

支持：

- 加减乘除
- `MOD`
- 括号
- `SIN/COS/TAN/ATAN`
- `ABS/SQRT`
- `ROUND/FIX/FUP`

角度函数使用角度制。

## 控制语句

```text
#100=10
#101=[#100+5]

IF [#100 GT 5] GOTO 200
GOTO 300

WHILE [#100 GT 0] DO 1
  G01 X#100
  #100=[#100-1]
END 1
```

## G 代码变量替换

```text
G01 X#100 Z[#100+#101] F#9
```

展开后变成普通 G 代码，再交给 GCodeParser 和 MotionPlanner。

## 安全限制

- 最大执行行数：20000
- 最大展开程序段：50000
- 单个 WHILE 最大循环次数：1000
- 未闭合 WHILE、缺失 END、无效 GOTO 和未赋值变量都会报错
